# Fantasy-points model — `lgbm-20261002-1515`

_Generated by `p11 model train`. Dream11 T20 points per player per IPL match, predicted at the toss (XIs known)._

## Protocol
- Training data: IPL 2008–2024, 27,700 player-match rows overall (no-results and fielding-only subs excluded); recency weights halve every 3 seasons.
- Tuning: rolling origin over 2020, 2021, 2022, 2023, 2024 (train on seasons < Y, score Y); trees chosen by early stopping on the last 74 *training* matches (about one season; never the scored fold). Grid: {"num_leaves": [15, 31], "min_child_samples": [40, 100], "learning_rate": [0.03]}.
- Test: one model on 2008–2024, scored once on 2025.
- Walk-forward: 2026 predicted in blocks of 10 matches, retraining on everything before each block.
- Baseline: last-5-form (mean of the player's last 5 IPL games; 0 for debutants).
- Best XI: Dream11 rules (11 players, 1–8 per role, max 10 per team, C ×2 / VC ×1.5, no credit cap) solved on the predictions, scored on actual points. CIs: paired bootstrap over matches (2000 resamples).

## Model
- LightGBM gradient-boosted trees, four heads: mean (L2) + quantiles p10 / p50 / p90 (pinball loss; sorted so they never cross).
- Chosen parameters: `{"num_leaves": 31, "min_child_samples": 100, "learning_rate": 0.03}` + fixed `{"feature_fraction": 0.8, "bagging_fraction": 0.8, "bagging_freq": 1, "lambda_l2": 1.0, "num_threads": 4}`.
- Trees per head (serving model, trained on ≤2026): `{"mean": 65, "q10": 50, "q50": 74, "q90": 79}`; test model: `{"mean": 89, "q10": 94, "q50": 92, "q90": 64}`.
- Learned values (leaf values + split thresholds, all heads): **16,348**.
- Features: **92** point-in-time features (see below). Run time 26 min.

Caveats:
- Fantasy points are very noisy: the mean head explains only a few percent of the variance of a single player's score; gains show up in rankings and XI totals, not in exact numbers.
- The 2025 test model is frozen for the whole season (trained on ≤2024); the 2026 walk-forward retrains every 10 matches, as the live product will.
- impact_in substitutes are included as rows although only the named substitutes are known at the toss.
- Player roles / batting hand / bowling type are current values for every season.
- p10–p90 coverage below the nominal 80% means the ranges are somewhat too narrow.
